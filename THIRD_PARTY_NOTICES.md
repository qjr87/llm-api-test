# Third-party notices

The model authenticity feature in this project is an original lightweight
integration inspired by the public model-fingerprinting work below. It is not
a verbatim copy of any repository and its verdicts are intentionally described
as behavioral estimates.

## ToseaAI/llm-fingerprint-detector

- Repository: https://github.com/ToseaAI/llm-fingerprint-detector
- License: MIT
- Relevance: behavioral fingerprinting of OpenAI-compatible endpoints and
  model-substitution detection.

## qiyongzheng/LLM-API-Verifier

- Repository: https://github.com/qiyongzheng/LLM-API-Verifier
- License: MIT
- Relevance: adapter-oriented orchestration and model identity verification.

## litemars/LLM-Fingerprinter

- Repository: https://github.com/litemars/LLM-Fingerprinter
- License: MIT
- Relevance: black-box probing across identity, behavioral, and style signals.

The feature currently uses a small five-probe browser-compatible detector. The
full research implementations require more probes and, in some cases, Python
or pre-trained reference models. Their results should not be represented as a
guarantee of model provenance.
